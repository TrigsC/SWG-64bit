# SWG-64bit

This repository is reserved for a community release of an experimental Apple Silicon, 64-bit SWGEmu Pre-CU client. **The source and setup process are not published here yet.** Please do not use this repository as installation instructions.

The release is being reviewed to keep original game assets, recorded client/server data, personal information, and credentials out of the public repository. The project is independent and is not affiliated with SWGEmu, Lucasfilm, Daybreak, or the upstream SWGVulkanClient maintainer.
