# Community and support

This repository is an independent, experimental fork of
[SWGVulkanClient](https://github.com/maddogg221/SWGVulkanClient). The upstream
[license](LICENSE.md) is retained unchanged, including its no-support clause.
The upstream maintainer's separate community guidance is preserved in
[vendor/SWGVulkanClient/COMMUNITY.md](vendor/SWGVulkanClient/COMMUNITY.md).

For this fork, use GitHub issues to propose a bounded change or report a
reproducible defect, and draft pull requests for work in progress. Read
[CONTRIBUTING.md](CONTRIBUTING.md) before including test evidence. Community
contributions are welcome within the license's personal, non-commercial terms;
there is no guarantee of support, review time, or complete game compatibility.
